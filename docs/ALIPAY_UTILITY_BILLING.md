# 支付宝生活缴费接入说明

## 当前状态

- 支付宝网页应用已经完成 RSA2 密钥配置与接口加签。
- 应用密钥保存在本机 `.secrets/alipay/`，不进入 Git。
- `ALIPAY_UTILITY_BILLING_ENABLED=false` 表示正式户号查询代码已就绪，但当前应用尚未启用生活缴费接口权限。
- 物业页同时保留支付宝余额同步和人工账单录入；未开通权限时人工录入作为兜底。

## 户号查询接口

水电户号查询使用 `alipay.ebpp.jfexport.instbill.query`，业务大类为 `JF`，电费子类为 `ELECTRIC`，水费子类为 `WATER`。请求必须提供户号 `bill_key` 和支付宝生活缴费收费机构编码 `charge_inst`。

接口返回机构账单列表，其中 `amount` 是账单金额，`balance` 是可选的账户余额。是否返回余额取决于具体收费机构的接口实现，不能把应缴金额替代成余额。

`alipay.ebpp.bill.get` 不是本项目的户号余额查询接口；迁移包中的旧“同步余额”路由也只是随机生成模拟金额，不能继续用于生产数据。

水、电、燃气机构接入支付宝生活缴费，需要收费机构或授权服务商完成行业准入、签约、接口联调和上线审核。未完成准入时，不应预置收费机构编码，也不应把开放平台加签状态展示成“生活缴费已开通”。

## 后续接入材料

1. 收费机构主体信息与营业执照。
2. 与水务、电力等收费机构的合作或授权材料。
3. 业务联系人、技术联系人和结算信息。
4. 收费机构提供的账单查询、缴费、销账或对账接口文档。
5. 支付宝生活缴费产品审核通过后的机构参数。

## 切换步骤

1. 完成收费机构或服务商准入。
2. 取得电力和水务对应的支付宝 `charge_inst` 编码并录入物业账户。
3. 在支付宝测试或联调环境验证 `alipay.ebpp.jfexport.instbill.query` 返回结果。
4. 将 `ALIPAY_UTILITY_BILLING_ENABLED` 改为 `true`。
5. 保留人工录入作为异常账单和历史账单的补录方式。
